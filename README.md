# 🤖 AI Chatbot (Gemini API)

An intelligent AI chatbot built using the Gemini API that adapts its responses based on user context through a unique mode-based system.

---

## 🚀 Features

### 💬 1. Real-Time Chat
- Interactive chatbot with streaming responses
- Maintains smooth conversational flow

### 🎓 2. Student Mode
- Explains topics like a teacher
- Generates:
  - Simple explanations
  - Key points
  - Short notes
  - Important questions

### 💼 3. Business Mode
- Provides professional insights
- Includes:
  - Summary
  - Key insights
  - Market impact
  - Opportunities

### 💬 4. Normal Mode
- General-purpose chatbot
- Answers queries without transformation

### 📘 5. Explain Text
- Converts raw text into structured knowledge
- Useful for learning and quick understanding

### 🖼️ 6. Image Analysis
- Upload images and get AI-based explanations
- Useful for diagrams, charts, and visuals

---

## 🧠 Key Concept

This chatbot is built on a **mode-based intelligence system**, where the same input generates different outputs depending on user context.

> Example:
> - Student Mode → Learning-focused explanation  
> - Business Mode → Insight-driven analysis
